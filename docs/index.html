Why Paykit exists

Without Paykit
  • Write your own wallet integration
  • Build a polling loop against Mezo RPC
  • Handle Transfer event parsing
  • Deploy and maintain backend infra
  • Wire up webhook delivery yourself
With Paykit
  • One <script> tag, any website
  • Worker polls the chain for you
  • Lazy eth_getLogs, no wasted queries
  • Cloudflare edge — zero cold starts
  • Webhook fires on confirmation

How it works

STEP 01

Embed the widget

Drop one script tag with your Mezo address and amount. The widget renders a "Pay MUSD" button instantly.

STEP 02

Buyer pays

Modal opens. Buyer pays from MetaMask (wallet flow) or manually sends MUSD to your address.

STEP 03

Webhook fires

Worker watches the chain with eth_getLogs. On confirmation: webhook POST, paykit:success event, tx hash.

Add to your site

<!-- replace data-merchant with your Mezo address -->
<script
  src="https://paykit.samsonsamuel531.workers.dev/widget.js"
  data-amount="10"
  data-merchant="YOUR_MEZO_ADDRESS"
  data-token="0x118917a40FAF1CD7a13dB0Ef56C86De7973Ac503"
  data-endpoint="https://paykit.samsonsamuel531.workers.dev"
></script>

// listen for payment confirmation
window.addEventListener('paykit:success', (e) => {
  console.log('confirmed', e.detail.tx_hash)
})
